# TurtleByteGames.github.io

Sitio público de Turtle Byte Games: página del estudio y políticas de privacidad de los juegos.
Solo contenido público: nada de código, keystores, configuración ni datos internos.

- `marca/`, `favicon.ico` y `estilo.css`: copias de la marca del estudio (logos A3, 5 colores). El original está en el repo del estudio; se actualizan juntos.
- `marca/logo-horizontal-claro-128.png`: logo para la firma de correo.
- `tipografias/`: Space Grotesk y JetBrains Mono, alojadas acá (sin Google Fonts), bajo SIL Open Font License 1.1 (`*-OFL.txt`).
